# Pemro Mobile

Starter aplikasi mobile menggunakan Flutter.

## Menjalankan aplikasi

1. Instal Flutter SDK dan Android Studio, atau sambungkan perangkat Android dengan USB debugging.
2. Dari folder proyek, jalankan:

   ```powershell
   flutter create .
   flutter pub get
   flutter run
   ```

`flutter create .` akan melengkapi folder platform seperti `android/`, `ios/`, dan `web/` tanpa mengganti kode aplikasi di `lib/main.dart`.
